## Lockfile policy

`pnpm-lock.yaml` at the workspace root is the single source of truth for JS/TS dependency resolution across `apps/*` and `packages/*`. Solidity dependencies are locked via `contracts/core-v4/lib/` git submodule commits (recorded exact commit hashes, not tags, once installed) plus `contracts/core-v4/foundry.toml` remappings. Neither lockfile is hand-edited; both are regenerated by the respective tool (`pnpm install`, `forge install`) and committed.
